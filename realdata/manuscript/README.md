# Manuscript Materials

This directory contains reproducibility materials for the paper "Channelling Multimodality Through a Unimodalizing Transport: Warp-U Sampler and Stochastic Bridge Sampling Estimator" submitted to the Journal of the American Statistical Association.

## Directory Structure

### reproduce_results.Rmd
- Rmarkdown file for generating reproducibility results
- Demonstrates Figure 6 and Table 2 from the paper
- Contains detailed explanations of all results

### figures/
- Final figures used in the paper
- Named according to figure numbers


## Generating Results

All figures and tables can be generated by running:

```R
# Start R in the project root directory
R
# Inside R, restore the environment
renv::restore()
# This will install all required packages including:
# - rmarkdown, knitr for report generation
# - kableExtra, gridExtra for table and figure formatting
# If any package is missing, you can install it manually:
# renv::install(c("rmarkdown", "knitr", "kableExtra", "gridExtra"))
# - All analysis packages listed in the R Package Dependencies section
```

Generate the report:
```R
# Inside R
setwd("manuscript")
# Generate HTML report (recommended for interactive viewing)
rmarkdown::render('reproduce_results.Rmd', output_format = "html_document")
```

Then the HTML report will be generated in `manuscript/reproduce_results.html`.
